# 🌍 EARTH: UNWRITTEN — The Divergent GTA & Civ Sandbox
> **«ГТА в плейстоцене, цивилизация на битуме и сатирический учебник истории будущего»**

**EARTH: UNWRITTEN** — это масштабная 2D-песочница с видом сверху, объединяющая адреналиновый геймплей классической 2D GTA (угон мамонтов и паровиков, физика инерции, сбивание пешеходов, 5 звёзд розыска со штурмом стражи) с симулятором эволюции цивилизации в духе *Dwarf Fortress* и *RimWorld*.

Действие разворачивается в альтернативной истории Земли, где человечество пошло по аномальному технологическому пути: вместо стандартной металлургии цивилизация развивалась через природный битум, серу, костяную пневматику и нефтяные двигатели с древнейших времен.

---

## ⚡ Ключевые Особенности

1. **GTA-Физика и Угон (Grand Theft Auroch):**
   - Пеший бой и езда на зверях и транспорте сквозь 4 эпохи: от диких туров и боевых мамонтов до битумных колесниц, паровых броневиков и антигравитационных спидеров.
   - Физическая модель с разгоном, торможением, инерцией, заносом и разрушительным тараном пешеходов с выбросом частиц крови и импульсом отдачи.
   - Клавиша **[F]** или **[E]** для мгновенного угона любого транспорта прямо из-под носа у хозяина.

2. **5 Звёзд Розыска (The Wanted System):**
   - ★☆☆☆☆ — Крик свидетеля, подозрение местной стражи, попытка задержания.
   - ★★☆☆☆ — Мобилизация городской стражи / патрульных, преследование бегом.
   - ★★★☆☆ — Кавалерия / Патрульные броневики, быстрый перехват на транспорте.
   - ★★★★☆ — Штурмовые отряды с арбалетами / винтовками / плазмой, заградительный огонь.
   - ★★★★★ — Чрезвычайное положение: королевские гвардейцы, тяжелые паровые джаггернауты / ховер-танки, приказ стрелять на поражение.
   - Сброс розыска через укрытие вне поля зрения стражи в течение 15 секунд.

3. **Матрица 4 Эпох (Хроноскачки):**
   - **Эпоха 1: Каменный Век** — шатры из шкур, костры, дубины, езда на шерстистых мамонтах и первобытных турах.
   - **Эпоха 2: Бронзово-Битумный Век** — смоляные зиккураты, каналы с сырой нефтью, копья, боевые колесницы.
   - **Эпоха 3: Паровой Век Железа** — кирпичные мануфактуры, булыжные мостовые, паровые броневики, револьверы.
   - **Эпоха 4: Нео-Мегаполис** — монолиты из обсидиана, неоновые автострады, плазменные карабины, грави-спидеры.

4. **Социальный AI и Облачка Речи (Speech Bubbles):**
   - Живые диалоги сотен жителей, стражников и бродяг прямо на игровом холсте над их головами.
   - Реакции на насилие, угоны, стрельбу, панику и смену эпох.

5. **Система «Грязной Эврики» (Dirty Eureka):**
   - Прогресс цивилизации двигают не академики, а городские маргиналы: нищие, рабы и бродяги случайно открывают порох, битумные смеси или расщепление ядра, роясь в отбросах.

6. **Школьный Архив Будущего (The School Archive):**
   - Сатирический учебник истории из 3500 года, где каждое ваше преступление, задавленный мамонтом стражник и угон повозки канонизируются как «священный подвиг Небожителя» и «очищение эры от скверны».

7. **Режим Бога (Cataclysms & Blessings):**
   - Мгновенный призыв метеорита с кратером и огненной волной, битумного мора или Золотого Века прозрения.

## 🕹️ Схема Управления

| Клавиша / Ввод | Действие |
| :--- | :--- |
| **[W] / [↑]** | Движение вперед / Ускорение транспорта (газ) |
| **[S] / [↓]** | Движение назад / Задний ход и тормоз |
| **[A] / [←]** | Движение влево / Поворот руля (влево) |
| **[D] / [→]** | Движение вправо / Поворот руля (вправо) |
| **[Мышь]** | Направление взгляда, прицеливание оружия |
| **[ЛКМ] / [Пробел]** | Атака (удар дубиной / копьем, выстрел, таран на скорости) |
| **[F] / [E]** | Сесть верхом / Угнать транспорт / Спешиться |
| **[1] - [4]** | Быстрое переключение оружия (если разблокировано) |
| **Кнопка «Хроноскачок»** | Прыжок на +500 лет вперед (смена эпохи при заполнении шкалы) |
| **Кнопка «Режим Бога»** | Панель вызова метеорита, чумы или золотого века |
| **Кнопка «Школьный Архив»**| Просмотр сатирического учебника истории ваших деяний |
| **Кнопка «Звук»** | Включение / выключение звукового синтезатора Web Audio API |

## 🚀 Руководство по Локальному Запуску

Проект **100% автономен**: не требует подключения к интернету, внешних библиотек, сборщиков (Webpack/Vite) или CDN. Все ресурсы, шрифты, графика и звуки генерируются процедурно в реальном времени.

### Вариант 1. Через Python (рекомендуется)
Если у вас установлен Python (3.x):
```bash
# Перейдите в папку проекта:
cd earth-unwritten

# Запустите локальный HTTP-сервер:
python3 -m http.server 8000

# Откройте в браузере:
# http://localhost:8000
```

### Вариант 2. Через Node.js (npx serve)
Если у вас установлен Node.js:
```bash
cd earth-unwritten
npx serve .
```

### Вариант 3. Через VS Code Live Server
1. Установите расширение **Live Server** в VS Code.
2. Откройте папку `earth-unwritten`.
3. Нажмите правой кнопкой мыши на `index.html` -> **"Open with Live Server"**.

### Вариант 4. Прямое открытие файла в браузере
Вы можете дважды кликнуть на файл `index.html` и открыть его в любом современном браузере (Chrome, Firefox, Safari, Edge). 
*Примечание:* Web Audio API автоматически активируется по первому клику или нажатию клавиши.

## 💻 Системные Требования и Архитектура

- **Движок рендера:** HTML5 2D Canvas с двойной буферизацией и сглаживанием векторных примитивов.
- **Частота кадров:** 60 FPS (адаптивная компенсация через `dt` в `requestAnimationFrame`).
- **Звук:** Процедурный синтезатор Web Audio API (генераторы белого шума, FM/AM-осцилляторы, огибающие ADSR, фильтры частот).
- **Поддерживаемые браузеры:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+.
- **Разрешение:** Адаптивное полноэкранное (Full HD / 4K / Ultrawide с учетом `window.devicePixelRatio`).
